# ✨ Sparkle

A Dynamic Island–style notch for Windows 10 and 11.

### [⬇️ Download the latest version](https://github.com/bryanvegards/SPARKLE---WINDOWS-NOTCH/releases/latest)

On that page, click **SparkleSetup-….exe** under **Assets** (not "Source code").

## What it does
- 🎵 **Music** with album art, waveform and synced lyrics
- ✅ **Tasks** in plain words ("gym 7-8pm tomorrow") with a week/month calendar
- 🎯 **Focus** timer (pomodoro)
- 💧 **Water** tracker with reminders
- 📝 **Notes**: a quick scratch pad, or save them
- ⭐ Twinkling stars when it's idle, and charging lights

## Installing
1. Download and run the installer.
2. If Windows says **"Windows protected your PC"**, click **More info → Run anyway** (the app isn't signed).
3. Sparkle appears at the top of your screen. It updates itself from then on.

Works on Windows 10 (1809+) and Windows 11, 64-bit.
